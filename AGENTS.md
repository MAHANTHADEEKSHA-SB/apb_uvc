# Repository guidance

For the experimental parameter-independent UVM architecture proof of concept, start with [docs/dv-architecture/AGENTS.md](docs/dv-architecture/AGENTS.md), then review the approved decisions and status documents it references.

The existing APB UVC code is not automatically covered by this experimental architecture contract. Any changes to the current APB implementation require a separate approved work item.

Build results must be supported by actual commands and logs. Do not treat an AI review as a replacement for compilation or simulation.
